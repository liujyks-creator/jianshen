# E16-12 Heart-rate recap visual reference

**Status:** Planning note; no Android implementation
**Date:** 2026-07-11
**Scope:** Future post-workout heart-rate recap information hierarchy and visual-gate inputs

## External Reference Boundary

用户提供的划船训练详情 / 图表截图可作为 E16-12 的外部视觉参考，但截图保留在用户本地下载目录，不复制、移动或提交到仓库。后续 E16-12a HTML 视觉评审可再次使用该参考。

参考的是信息层级，不是运动项目或厂商 UI 的逐像素复刻：训练标题与时间、关键摘要、心率时间序列、区间时长和克制的训练参考说明。TrainFlow 不复制划船机专属距离、配速、桨频、功率、卡路里、恢复时长或“训练压力”结论。

## E16-12 Target

E16-12 的实际呈现归属为单次训练记录详情，而不是训练中浮动胶囊。只有在训练中存在已保存、带来源边界的心率样本时，才允许显示：

- 总训练时长与心率数据覆盖情况；
- 平均心率与最高心率；
- 心率随时间变化的曲线；
- 各心率区间的停留时长 / 占比；
- 明确标注为训练参考、非医疗结论的简短说明。

区间颜色沿用已确认的 TrainFlow 规则：热身冷色、燃脂绿色、有氧黄色、无氧橙色、极限红色，超过用户提醒阈值仅使用深红视觉提示。年龄缺失或样本覆盖不足时，必须降级显示真实可用数据，不能推导区间或补假平均值。

## Delivery Sequence

1. E16-10 定义 stale / offline、显式重连和重试边界，保证训练中的数据状态可信。
2. E16-11 定义并实现训练中 1 秒采样、来源、覆盖状态、持久化和 session 关联。
3. E16-12a 使用 `huashu-design` 产出至少两种 HTML 高保真复盘方案，并在现有 TrainFlow 记录详情层级、720x1280 和长内容下完成视觉评审。
4. 用户确认方案后，E16-12 才实现记录详情、图表和区间分析。

## Non-goals

- 不恢复旧心率卡片、`未获取心率`占位、手动心率输入或旧平均心率趋势。
- 不将瞬时 `HeartRateState` 直接当作历史事实。
- 不做医疗诊断、风险告警、自动训练中断或未经单独模型验证的恢复建议。
- 不在 E16-10 或 E16-11 提前实现本页 UI、图表或分析。
