E16-3a 心率浮动胶囊视觉方案

当前推荐方向是 TrainFlow App 内可拖动浮动心率胶囊。它是 app shell overlay，不使用系统级悬浮窗权限，不参与训练页排版，也不挤压 TimerDial、力量 active/rest/confirm-record 或固定底部主按钮。

本轮结论: 旧顶部 status pill 已降级为 superseded exploration。推荐方案只保留浮动胶囊：点击展开 / 收起，拖动超过阈值才进入 dragging，松手后吸附到左右安全边，不能停在主按钮、输入、confirm-record、底部导航、键盘、状态栏或手势导航区上。

非系统悬浮窗只在 TrainFlow app 内显示，不申请 draw-over-other-apps。
辅助层级心率低于当前动作、主时间、组目标、记录确认和主按钮。
无训练只显示连接或 bpm，不写训练记录。
训练中表达未来 1s sampling 边界，本 HTML 不实现记录模型。
