# TrainFlow 决策日志

**状态:** 活跃产品决策记录

## 状态标签

| 标签 | 含义 |
|---|---|
| Accepted | 当前基线，后续工作默认按此执行。 |
| Reserved | 预留接口或边界，但当前不交付完整能力。 |
| Open | 仍需继续决策或收窄首版定义。 |
